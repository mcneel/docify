# Docify (Archived)

This project has been archived and is no longer maintained.

Docify generated the RhinoCommon and Grasshopper API documentation. It has been replaced by
[Owl](https://github.com/mcneel/Owl), which is available on NuGet as
[McNeel.Owl](https://www.nuget.org/packages/McNeel.Owl).

## Where To Go Now

- **API Docs:** [developer.rhino3d.com/api](https://developer.rhino3d.com/api/)
- **Issues And Contributions:** open them on [Owl](https://github.com/mcneel/Owl/issues); this repository is read-only.

## Last State

The last source published here was Rhino v9.0.26293 (beta), in October 2026. The original README, with build and
usage notes, is kept in [README_ARCHIVED.md](README_ARCHIVED.md).
